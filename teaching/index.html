教學

課程講義與投影片

給學生的課程講義與投影片下載區，依「課程／學期／主題」分組。

目前為佔位架構，尚未放上實際檔案。檔案請放在 teaching/files/ 資料夾，並依下方格式加入連結。

課程

課程：（待填寫課程名稱）

學期：（待填寫，例如 114 學年度第 1 學期）

  • 主題 1：（待填寫主題名稱） 講義 PDF（待上傳） 投影片（待上傳）
  • 主題 2：（待填寫主題名稱） 講義 PDF（待上傳） 投影片（待上傳）
  • 主題 3：（待填寫主題名稱） 講義 PDF（待上傳） 投影片（待上傳）

課程：（待填寫第二門課程名稱）

待填寫 / To be added可依相同格式新增更多課程與學期。

檔案連結格式範例

把檔案放進 teaching/files/ 後，在主題清單中加入下面這樣的項目（href 使用相對路徑，不要以斜線開頭）：

<li class="topic">
  <span class="topic-name">主題 1：放射治療原理</span>
  <a class="file-link" href="files/114-1/topic-01-handout.pdf" download>講義 PDF</a>
  <a class="file-link" href="files/114-1/topic-01-slides.pdf" download>投影片 PDF</a>
  <a class="file-link" href="https://example.com/shared-link" target="_blank" rel="noopener">雲端連結</a>
</li>
