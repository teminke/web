# 字型 / Fonts

`tmk-round-*.woff2` 是由開源字型 **jf open 粉圓 2.1**（justfont，SIL Open Font License 1.1，
https://github.com/justfont/open-huninn-font ）裁切而成的子集，並依 OFL 的保留字型名稱規定更名為「TMK Round」。
授權全文見 `LICENSE-jf-open-huninn.txt`。

- `tmk-round-site.woff2`：本站目前用到的所有字元（每頁都會載入）。
- `tmk-round-l1-1 ~ 4.woff2`：Big5 常用字其餘部分，依 `unicode-range` 只在頁面用到時才載入。

若新增內容出現這些檔案都沒有的罕見字，瀏覽器會自動改用 Noto Sans TC 顯示，不會變成方框。
