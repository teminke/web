衛教專區

放射治療衛教

用圖解和小動畫，陪您與家人更安心地走過治療的每一個階段。先看自己治療部位的那一篇，再看一般照護；想了解治療機器與技術、或同意書上寫的風險，也有專篇說明。

本專區文章依據臨床指引與已發表的研究撰寫，目前為醫師審閱中的草稿版本；每篇都標示更新日期與參考來源。

依治療部位

先看自己治療部位的那一篇。

頭頸部放射治療：注意事項與照護

頭頸部放射治療常見的反應包括口腔黏膜炎、口乾、味覺改變、皮膚反應與牙關緊閉。多數反應是暫時的，只要提早準備、每天好好照顧，就能把不舒服降到最低、順利完成療程。

頭頸部放射治療復健運動

放射治療或手術後，頸部與咀嚼肌肉可能慢慢變緊、變硬，造成張口困難與脖子僵硬。這些變化可以預防：從治療第一天開始，每天花幾分鐘做下面的運動，並持續到治療結束後。

閱讀全文 →

乳房放射治療：副作用與自我照護

乳房或胸壁的放射治療通常在手術後進行，療程約三到六週。最常見的反應是皮膚變紅、乳房腫脹與疲倦，大多在治療結束後幾週內改善。這一頁告訴您每個階段可以怎麼照顧自己。

閱讀全文 →

胸部及上腹部放射治療：副作用與自我照護

照射食道、肺、縱膈腔、胃、肝臟或胰臟等部位時，常見的反應是噁心、吞嚥疼痛、咳嗽、皮膚反應與疲倦。知道它們何時出現、怎麼處理，就能安心完成治療。

閱讀全文 →

下腹部（骨盆腔）放射治療：副作用與自我照護

骨盆腔放射治療用於子宮頸癌、子宮內膜癌、攝護腺癌、膀胱癌、直腸癌與肛門癌等。常見反應包括腹瀉、頻尿、皮膚皺摺處反應與疲倦，也可能影響性功能與生育。多數急性反應在治療後數週改善。

一般照護

治療前、中、後都用得到的照護。

治療前準備：放射治療會怎麼進行？

第一次接受放射治療，難免緊張。了解從門診、定位到每天治療的流程，以及可以事先準備的事，會讓整個過程安心許多。

閱讀全文 →

治療中注意事項：日常生活怎麼過？

放射治療期間，大部分的日常生活都可以照常進行。這一頁整理治療期間的作息、飲食、活動、情緒與用藥等常見問題，陪您把每一天過得安穩。

閱讀全文 →

皮膚照護：放射治療期間怎麼保護皮膚？

照射部位的皮膚會像曬傷一樣變紅、乾燥、脫屑，少數會破皮。好消息是：溫和清潔、保濕與避免刺激，就能讓大多數人舒服地度過；許多以前的禁忌（例如不能洗澡、不能用止汗劑）已被研究推翻。

閱讀全文 →

飲食與營養：治療期間怎麼吃？

治療期間，身體需要更多的熱量與蛋白質來修復正常組織。吃得夠、吃得對，能幫助您維持體重與體力、減少中斷治療的機會。這一頁提供一般原則，細節請與營養師討論。

閱讀全文 →

治療後追蹤：結束治療之後呢？

放射治療結束不代表照顧結束。接下來的幾週是副作用逐漸消退的時期，之後則是規律追蹤與重建健康生活的階段。這一頁說明可以期待什麼、要注意什麼。

這裡整理病人與家屬在門診最常問的問題。若您的狀況特殊，仍請以您的醫療團隊的說明為準。

治療技術與設備

治療機器怎麼運作、每次治療時發生什麼事。

認識直線加速器與真光刀：放射治療是怎麼進行的

大多數放射治療都是用「直線加速器」完成的。這一頁用圖解說明機器怎麼運作、治療室裡會看到與聽到什麼、強度調控與弧形治療是什麼，以及新一代機器（例如真光刀）多了哪些功能。

閱讀全文 →

螺旋刀（Tomotherapy）：螺旋式的強度調控與每天的斷層影像

螺旋刀是一種環形的直線加速器：機頭像電腦斷層一樣繞著您轉，治療床同時慢慢前進，放射線以螺旋的路徑一層一層照射。每次治療前它會用自己的斷層影像對位。這一頁說明它的原理、流程、適合的情況與您會經歷的事。

閱讀全文 →

影像導航放射治療（IGRT）：每次治療前先「對位」

腫瘤與器官的位置每天都會有些許不同。影像導航放射治療在每次照射前先拍影像、與治療計畫比對，再把治療床移到正確位置，讓放射線準確落在腫瘤上、少照到正常組織。這一頁說明它怎麼做、有哪些影像方式，以及您可以怎麼配合。

閱讀全文 →

呼吸調控放射治療：深吸氣閉氣與呼吸門控

肺、肝與乳房會隨著呼吸移動。呼吸調控技術讓放射線只在腫瘤位於預定位置時照射，或讓您在深吸氣閉氣時接受治療，使心臟與肺離開照射範圍。這一頁說明有哪些方式、流程怎麼走，以及在家怎麼練習閉氣。

閱讀全文 →

腦部立體定位放射手術（SRS）：流程、副作用與照護

立體定位放射手術不是開刀，而是用許多方向的細小射束聚焦在腦部病灶上，一到五次就完成高劑量的治療，病灶外的劑量快速下降。這一頁說明誰適合、流程怎麼走、可能的副作用，以及治療期間與之後怎麼照顧自己。

閱讀全文 →

身體立體定位放射治療（SBRT）：肺、肝、脊椎、攝護腺與其他部位

身體立體定位放射治療用少次數、高劑量、極精準的照射來治療身體各處的小型腫瘤，通常一到五次（最多八次）完成。它需要嚴格的固定、呼吸管理與每次治療前後的影像確認。這一頁先說明共通的流程與準備，再分部位說明特別要注意的事與可能的副作用。

治療說明與同意

同意書在說什麼、各部位可能的副作用與風險。

放射治療說明與同意書：簽名前您該知道的事

開始放射治療前，醫師會說明治療並請您簽署「說明暨同意書」。它不是免責聲明，而是把治療的目的、流程、禁忌、可能的風險與替代方案寫下來，讓您在充分了解後做決定。這一頁逐段說明同意書在講什麼、哪些字句容易讓人害怕、簽名前該告訴醫師的事，以及您的權利。

閱讀全文 →

各部位放射治療的副作用與風險一覽

放射線治療的副作用取決於「照到哪裡」：每個部位都有自己的一組急性、慢性與罕見反應。這一頁把同意書上會出現的項目整理成一張互動地圖，點選部位就能看到可能的反應、為什麼會發生，以及對應的照護文章。

閱讀全文 →

兒童放射治療：給家長的說明

孩子的身體還在發育，放射治療的考量和大人不一樣：怎麼讓孩子安心地保持不動、急性反應怎麼照顧，以及生長、學習、荷爾蒙與生育等長期影響要怎麼追蹤。這一頁寫給家長，也可以念給大一點的孩子聽。
