治療技術與設備

影像導航放射治療（IGRT）：每次治療前先「對位」

腫瘤與器官的位置每天都會有些許不同。影像導航放射治療在每次照射前先拍影像、與治療計畫比對，再把治療床移到正確位置，讓放射線準確落在腫瘤上、少照到正常組織。這一頁說明它怎麼做、有哪些影像方式，以及您可以怎麼配合。

本文依據臨床指引與已發表的研究整理，為草稿版本，將由柯德敏醫師審閱定稿；內容為一般性衛教，不能取代您的醫療團隊針對個人狀況的說明。

適合誰看
適用於所有接受體外放射治療的病人，特別是胸腔、腹部與骨盆腔治療，以及少次數高劑量的立體定位治療。

一眼看懂

每次治療前對位誤差修正到幾公釐
X 光或斷層影像1 到 2 分鐘
需要時植入金標記米粒大、終身不用取出
您的準備一樣重要膀胱直腸每天一致
看完整的重點整理
  • 「在正確的位置給正確的劑量」是放射治療最重要的事；影像導航就是每次治療前確認位置的方法。
  • 常用的方式有兩張互相垂直的 X 光（2D）、錐狀射束電腦斷層（3D CBCT）、依呼吸分期的 4D CBCT，以及體表攝影監測；醫師依部位選擇。
  • 影像比對後治療床會自動微調，通常只有幾公釐；修正完才開始照射。
  • 在肝臟或攝護腺等軟組織腫瘤，可能先植入兩到三顆米粒大的金屬標記，讓 X 光看得到腫瘤的位置，治療中也能持續追蹤。
  • 影像的輻射劑量很低，整個療程累積起來通常不到一天治療劑量的一半；換來的是更小的照野。
  • 您能做的：每天用一樣的方式準備膀胱與直腸、保留皮膚記號、治療中保持不動、依指示呼吸。

每次治療的對位流程

  1. 雷射對皮膚記號

    先依皮膚記號與固定模具擺位，這是粗略的第一步。

  2. 拍影像

    機器拍兩張正交 X 光，或轉一圈拍錐狀射束電腦斷層，約 1 到 2 分鐘。

  3. 與計畫比對

    電腦把今天的影像與定位影像重疊，算出前後、左右、上下與旋轉的差距；治療師檢查腫瘤與器官是否對上。

  4. 治療床修正

    差距通常是幾公釐，治療床由遙控自動移動到正確位置。

  5. 照射與治療中監測

    開始照射；部分機器在照射中仍持續拍影像或監測體表，移動超過範圍就自動暫停。

四種常見的影像導航方式

方式看到什麼常用在您會經歷
2D 正交 X 光（kV／MV）骨頭與植入的金屬標記；軟組織看不清楚。頭頸、腦部、四肢、脊椎等以骨頭為準的部位。機頭與影像板轉到兩個角度各拍一張，約一分鐘。
3D 錐狀射束電腦斷層（CBCT）腫瘤、膀胱、直腸、肝臟等軟組織的立體影像。胸腔、腹部、骨盆與立體定位治療。機器繞您轉一圈，約一到兩分鐘，請保持不動、平緩呼吸。
4D CBCT把呼吸週期分成多個時相，看出腫瘤隨呼吸移動的範圍。無法閉氣的肺與上腹部病灶。掃描時間較長（兩到四分鐘），正常呼吸即可。
體表攝影監測（SGRT）攝影機追蹤體表上千個點的位置，不用輻射。乳房、閉氣治療、頭部開放式面罩。治療部位不覆蓋衣物，攝影機投射條紋光；移動時射束自動停止。

治療中追蹤技術（治療中定時拍影像、以金屬標記監測）會在立體定位治療時視需要加上。

為什麼位置每天會不一樣

器官會動、身體會變

  • 膀胱與直腸的充盈程度會推動攝護腺、子宮頸與直腸腫瘤；呼吸讓肺與肝的腫瘤上下移動一到三公分；手術後的水腫、療程中腫瘤縮小與體重減輕也會讓體內結構移位。只靠皮膚記號對位，這些變化都看不到。
更多說明

證據怎麼說：二十年前的做法是以傳統底片拍攝比對，費時且解析度低，因此無法每天執行；錐狀射束電腦斷層讓每日三維影像成為可能（Jaffray 2002），已是現代放射治療的標準配備（Dawson 2006）。

照野越準，邊緣可以越小

  • 治療計畫在腫瘤外都會多留一圈「安全邊緣」來涵蓋擺位誤差。每天對位後，誤差變小，邊緣就能縮小，正常組織的劑量跟著降低。
更多說明

證據怎麼說：攝護腺癌的研究顯示，每日影像導航下提高劑量，三年內嚴重泌尿道晚期副作用由 20% 降到 10%（Zelefsky 2012）；隨機試驗也證實每天對位比每週對位的直腸副作用更少（de Crevoisier 2018）。

金屬標記與治療中追蹤

為什麼要植入金屬標記

  • 植入是門診的小手術，約 15 到 30 分鐘，通常只需局部麻醉；植入後一週左右才定位，讓標記位置穩定。
  • 可能的不適：穿刺處疼痛或少量出血（約每一百人有一到四人），攝護腺植入後可能短暫血尿或血精；極少數標記會移位或隨血流跑到別處。
  • 服用抗凝血藥物的人請事先告知，可能需要暫停幾天。
更多說明

X 光看得到骨頭，卻看不清肝臟或攝護腺裡的腫瘤。在超音波或電腦斷層導引下，醫師用細針把兩到三顆純金或鉑金的小標記放在腫瘤內或旁邊；之後每次治療的影像就能以標記為準對位，立體定位治療時還能在照射中持續監測它們是否移動。

證據怎麼說：經皮植入標記的併發症少，多為輕微疼痛與少量出血（Kothary 2009）；攝護腺植入後的感染率低但不是零，術前會給預防性抗生素（Loh 2015）。

治療中也在看

  • 立體定位治療時，機器可在照射中每隔幾秒拍一張 X 光，自動比對標記或骨頭的位置；超出容許範圍就暫停，重新對位後再繼續。體表攝影監測則用光學方式追蹤皮膚表面，適合乳房與腦部治療。
更多說明

證據怎麼說：以 X 光即時追蹤體內標記的技術最早由日本團隊建立，可把會隨呼吸移動的腫瘤誤差控制在數公釐內（Shirato 2000）；體表監測的精確度在次公釐等級（Hoisak 2018）。

您可以怎麼配合

每天一樣的準備

  • 骨盆治療：依指示在治療前喝固定量的水憋尿，或排空直腸；若當天腸胃狀況不同，請告訴治療師。
  • 上腹部治療：依指示空腹或在固定時間進食，讓胃的大小一致。
  • 皮膚記號不要洗掉，模糊了請治療師補畫；面罩或模具變鬆要說。
更多說明

影像可以修正機器看得到的差距，但器官的「狀態」要靠您維持一致。

  • 治療中保持放鬆、不要移動；需要咳嗽或不舒服就舉手，治療會暫停。

影像的輻射劑量

  • 一次 kV 錐狀射束電腦斷層的劑量約 1 到 3 cGy，正交 X 光更低；一次治療的劑量通常是 180 到 200 cGy 以上。整個療程的影像劑量加起來約相當於治療劑量的百分之一到三，而且集中在治療範圍附近。醫學物理師會依部位選擇最低而足夠的影像設定。
更多說明

證據怎麼說：美國醫學物理學會第 75 號工作小組建議把影像劑量納入考量並盡量降低，同時指出它遠小於治療劑量，不應因此放棄影像導航的好處（Murphy 2007）。

影像導航期間：這樣做、別這樣做

這樣做

  • 固定時間喝固定量的水
  • 依指示空腹或進食
  • 保留皮膚記號
  • 拍影像時保持不動

別這樣做

  • 治療前喝大量咖啡或茶
  • 憋不住還硬撐
  • 搓掉記號
  • 植入標記前自行停抗凝血藥

對位的四個步驟

  1. 雷射對皮膚記號

  2. 拍今天的影像

  3. 與計畫重疊比對

  4. 治療床自動修正

問與答

每次都要拍影像嗎？

依部位而定：立體定位治療與骨盆、胸腹治療通常每天拍；有些部位每天拍 X 光、每週拍一次 CBCT。醫師會為您的治療訂出影像計畫。

對位的結果我看得到嗎？

可以請治療師或醫師在回診時給您看今天的影像與計畫影像的重疊圖，許多病人覺得看過之後更安心。

如果我憋尿憋不住怎麼辦？

請直接告訴治療師，不要勉強；他們會調整喝水的時間與量，或讓您先上廁所再重來。對位時影像會顯示膀胱是否足夠。

金屬標記會永遠留在身體裡嗎？

會，它們只有米粒大、不含磁性，不影響日後的核磁共振與機場安檢，也不需要取出。

體表監測的攝影機會拍下我的影像嗎？

系統記錄的是體表的立體座標點，不是照片；資料只用於治療對位。

今天的自我照護打卡

每天勾一勾，看看自己做到了多少；勾選會記在這台裝置上，隔天自動歸零。

0 / 4 完成

紅黃綠燈：該怎麼辦？

綠燈：正常反應，安心照顧

  • 對位花了比較久
  • 植入標記處微痛一兩天

黃燈：下次門診告訴團隊

  • 憋尿越來越困難
  • 腹瀉讓直腸準備不一致
  • 標記處疼痛超過三天

紅燈：立刻聯絡醫療團隊

  • 植入標記後：持續出血、發燒、劇烈腹痛或解不出尿。
  • 治療中突然劇烈不適：舉手或出聲，治療會立刻暫停。

夜間與假日請至急診

治療結束後

  • 每日影像會與治療紀錄一起保存，是日後評估療效與副作用的重要資料。
  • 植入的金屬標記不需要處理；做其他檢查時可以告知醫師體內有標記。
